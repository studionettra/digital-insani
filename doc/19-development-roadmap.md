# Development Roadmap

## Phase 0 — Decisions & onboarding ✅

Complete: - Midtrans approval; - monthly transaction volume for Merchant
Support; - final product categories; - refund policy; - Terms; - Privacy
Policy; - guest checkout/account behavior; - email update behavior; -
invoice PDF decision; - final branding approval.

## Phase 1 — Foundation ✅

Build: - Laravel project; - MySQL; - Inertia + React; - Tailwind; -
Filament; - authentication; - base layouts; - design tokens; -
environments.

## Phase 2 — Catalog ✅

Build: - categories; - products; - product detail; - previews; - home; -
catalog filters.

## Phase 3 — Checkout ✅

Build: - order creation; - Midtrans Snap integration; - external ID
prefix (`DIGIPROD-`); - webhook with signature verification; -
idempotency; - payment status; - success/failure handling.

Note: Originally planned for Xendit, migrated to Midtrans on 1 Sep 2026.

## Phase 4 — Membership ✅

Build: - member area; - entitlement; - purchased products; - secure
download; - download audit.

## Phase 5 — Google Drive ✅

Build: - service account; - Drive API service; - version/file mapping; -
controlled delivery; - error handling.

## Phase 6 — Product updates ✅

Build: - product versions; - changelog; - member update page; - email
notification only if approved.

## Phase 7 — SEO & tracking ✅

Build: - articles; - sitemap; - metadata; - Open Graph; - GTM; - GA; -
Facebook Pixel; - consent.

## Phase 8 — Admin operations ✅

Complete: - Filament resources; - order monitoring; - settings; - basic
dashboard; - operational audit.

## Phase 9 — Hardening

Perform: - automated tests; - security review; - payment webhook
tests; - download authorization tests; - mobile QA; - social preview
QA; - production deployment rehearsal.

## Phase 10 — Production

Only after Midtrans approval: - production payment credentials; - live
webhook; - real transaction test if allowed; - monitoring; - launch.
